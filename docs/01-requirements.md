# 需求与质量属性

## 1. 项目目标

本项目实现一个可运行的轻量 3D 游戏引擎课程设计。评价重点如下：

| 目标 | 说明 |
|---|---|
| 可运行 | 能从编辑器创建、保存、加载并播放一个完整示例场景 |
| 边界清晰 | 引擎模块、编辑器、游戏脚本之间保持单向依赖和明确接口 |
| 可论证 | 每项关键架构选择都有 ADR、替代方案和取舍说明 |
| 可替换 | 渲染、物理、资产和脚本宿主通过接口隔离，可在不修改场景层的情况下替换实现 |
| 可测试 | 核心规则由自动测试覆盖，另提供隐藏窗口渲染和端到端脚本测试 |

## 2. 用户与用例

| 角色 | 目标 | 典型操作 |
|---|---|---|
| 课程评审者 | 在全新环境验证工程可构建、可演示 | 按 README 构建、运行、播放示例、查看架构文档 |
| 场景设计者 | 快速验证玩法原型 | 选择/创建实体、编辑 Transform 和组件、保存/加载、Play/Stop |
| 玩法程序员 | 用 C# 编写玩法逻辑 | 读取输入、移动角色、查询世界、触发事件、输出日志 |
| 引擎维护者 | 在不破坏边界的前提下替换实现 | 新增 `IRenderer`、`IPhysicsWorld` 或 `IAssetDatabase` 实现 |

## 3. 功能需求

| 编号 | 需求 | 优先级 | 验收方式 |
|---|---|---|---|
| FR-01 | 创建 GLFW 窗口和 OpenGL 4.1 上下文，支持固定时间步主循环 | 必须 | 窗口与隐藏窗口冒烟测试 |
| FR-02 | 实体具有 generation，删除后旧句柄不得访问新实体 | 必须 | 单元测试 |
| FR-03 | 支持 Transform、层级、相机、网格、光照、碰撞、角色、脚本和标签组件 | 必须 | 场景往返测试 |
| FR-04 | 支持父子层级变换传播并拒绝循环父子关系 | 必须 | 单元测试 |
| FR-05 | 支持场景 JSON 保存/加载；非法场景不得替换当前场景 | 必须 | 单元测试和手工加载 |
| FR-06 | 支持 `.meta.json` GUID、资产扫描、OBJ、PNG、材质加载 | 必须 | 资产测试与运行时冒烟 |
| FR-07 | 支持离屏视口、深度测试、Blinn-Phong、方向光、最多 8 个点光 | 必须 | 隐藏窗口像素读回 |
| FR-08 | 支持 AABB/球体碰撞、触发器、射线、重力和运动学角色 | 必须 | 物理单元测试与示例场景 |
| FR-09 | 支持 C# NativeAOT 脚本插件、ABI 校验、实例生命周期和事件回调 | 必须 | 端到端脚本测试 |
| FR-10 | 编辑器提供 Hierarchy、Inspector、Assets、Console、Viewport、选择、创建/删除、Play/Stop、保存/加载 | 必须 | 可见窗口截图与操作清单 |
| FR-11 | Play 前保存场景快照，Stop 后完整恢复 | 必须 | `EditorSession` 测试与手工演示 |
| FR-12 | 隐藏窗口、限制帧数、截图和性能场景可重复运行 | 应有 | 命令行冒烟与性能验收 |

## 4. 非功能需求与质量场景

### 4.1 性能

| 项目 | 场景 | 目标 | 当前结果 |
|---|---|---|---|
| QAS-01 | 500 实体、101 个可渲染对象、1280×720、关闭 VSync | 开发机稳定 60 FPS 以上 | Release 约 1482.7 FPS；Debug 约 284.2 FPS |
| QAS-02 | 单帧输入尖峰 | 固定步长最多补 5 步，不产生模拟失控 | `FixedTimestep` 单元测试通过 |
| QAS-03 | 编辑器空闲渲染 | 无可感知卡顿 | 隐藏窗口 120 帧通过；可见窗口截图正常 |

### 4.2 可修改性

| 项目 | 场景 | 目标 |
|---|---|---|
| QAS-04 | 将 OpenGL 渲染器替换为其他后端 | 场景层只依赖 `RenderFrame`，不需要修改 ECS/场景代码 |
| QAS-05 | 将简单物理替换为其他物理实现 | 通过 `IPhysicsWorld` 注入，编辑器和脚本层不依赖具体实现 |
| QAS-06 | 新增资产来源 | 通过 `IAssetDatabase` 隔离，渲染器只消费 CPU 侧资产数据 |
| QAS-07 | 新增脚本宿主 | 通过 `IScriptHost` 隔离，编辑器只读取目录和运行状态 |

### 4.3 可测试性

| 项目 | 场景 | 目标 |
|---|---|---|
| QAS-08 | 无显示器环境执行核心测试 | 除 OpenGL 冒烟外均可无窗口运行 |
| QAS-09 | 渲染回归 | 隐藏窗口读回像素，验证非清屏颜色和深度顺序 |
| QAS-10 | C# 玩法回归 | CTest 自动调用真实 NativeAOT DLL，验证移动、触发、拾取和异常隔离 |

### 4.4 错误隔离与恢复

| 项目 | 场景 | 目标 |
|---|---|---|
| QAS-11 | 场景文件损坏或版本不支持 | 返回错误，当前 World 保持不变 |
| QAS-12 | 资产 GUID 缺失或导入失败 | 返回错误并记录日志，不崩溃 |
| QAS-13 | `GameScripts.dll` 缺失 | 引擎继续加载和渲染场景，只禁用脚本 |
| QAS-14 | ABI 版本不匹配 | 拒绝加载插件并显示错误，不调用不兼容函数 |
| QAS-15 | C# 脚本抛异常 | 异常被 C# 边界捕获，脚本实例被禁用，引擎继续运行 |
| QAS-16 | Play 期间修改场景 | Stop 后恢复到播放前快照 |

### 4.5 可用性与可理解性

| 项目 | 场景 | 目标 |
|---|---|---|
| QAS-17 | 新成员查看模块关系 | README、架构图和 ADR 能在 30 分钟内说明主要边界 |
| QAS-18 | 评审者复现实验 | 构建、运行、测试和演示命令均有明确文档 |

## 5. 约束

| 编号 | 约束 |
|---|---|
| C-01 | 目标平台限定 Windows 10/11 x64，使用 CMake + MSVC |
| C-02 | 使用 GLFW、glad、glm、stb_image、Dear ImGui、nlohmann/json；不使用 Assimp、Jolt、Bullet、EnTT 等引擎级库 |
| C-03 | ECS、场景序列化、OBJ 解析、资产数据库、物理和编辑器均自行实现 |
| C-04 | 不引入多线程、网络、音频、骨骼动画、通用刚体动力学和热重载 |
| C-05 | C# 只能通过 C ABI 访问引擎，不得引用 C++ 头文件 |
| C-06 | 所有字符串跨 ABI 使用 UTF-8 指针和长度，不传递 STL、glm 或 C++ 对象 |
| C-07 | 输入、模拟、脚本、渲染和 ImGui 全部在主线程执行 |

## 6. 明确不做

| 领域 | 不实现内容 |
|---|---|
| 渲染 | PBR、全局光照、阴影（当前未实现）、骨骼动画、地形、后处理和级联阴影 |
| 物理 | 旋转 OBB、关节、连续碰撞、完整刚体角动量和多物理后端并行 |
| 编辑器 | 多级撤销重做、拖拽 Gizmo、材质节点编辑、发布打包和资源导入 GUI |
| 脚本 | 热重载、程序集卸载、独立进程调试和跨语言调试器 |
| 平台 | 音频、网络、多人同步、移动端和 Web |

## 8. 可裁剪范围

若后续时间不足，按下列顺序裁剪，不得破坏核心边界：

| 顺序 | 可裁剪项 | 保留原因 |
|---|---|---|
| 1 | Shadow Map | 属于渲染增强，不影响架构主链路 |
| 2 | 视口内 Gizmo | 编辑器可用数值编辑替代 |
| 3 | 资产拖拽 | 资产浏览和 GUID 解析仍保留 |
| 4 | 旋转/缩放 Collider | 示例物理闭环只依赖世界轴 AABB/球体 |

以下内容不得裁剪：C# ABI 端到端验证、场景快照恢复、非法输入错误隔离、架构与接口文档。
